# Attendance Management System

A robust Attendance Management System built with **.NET 8** designed to efficiently track, manage, and process user attendance, roles, and administrative workflows.

---

## 🚀 Features
* **Automated Tracking:** Streamlined check-in and check-out processing.
* **Database Integration:** Secure data storage and robust database queries.
* **Role Management:** Comprehensive administration tools for managing permissions and users.
* **Responsive Layout:** Clean architecture supporting modern web standards and asset structures.

---

## 🛠️ Technology Stack
* **Framework:** .NET 8 (C#)
* **Architecture:** ASP.NET Core MVC / Web Application
* **Asset Handling:** Standard static file hosting via `wwwroot/`

## ⚙️ Getting Started

### Prerequisites
* Ensure you have the [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) installed.
* Use Visual Studio 2022 or VS Code.

### Installation & Execution
1. Open your terminal in the root project folder.
2. Configure your database connection strings inside `appsettings.json`.
3. Run the application using the command:
   ```bash
   dotnet run
   ```
4. Navigate to the local localhost URL provided in your terminal output.
